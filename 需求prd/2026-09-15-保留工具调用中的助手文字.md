# 2026-09-15 保留工具调用中的助手文字

## 背景/原因

Web 对话生成过程中，助手可能在调用工具的同时输出进度说明，例如“端口通了，jobsdb 页面也加载出来了”。这类文字目前会和工具调用、工具结果一起放在过程折叠区中；任务完成后过程区默认收起，用户看不到已经生成过的说明，容易误以为内容被删除。

## 具体设计

- 变更位于入口层 / Channel Layer 的聊天展示层，不修改 FastAPI 接口、会话数据结构、Agent Runtime、Agent Loop 或工具执行顺序。
- 完成的聊天轮次如果包含带工具调用的助手文字，过程区默认保持展开，让这类文字在最终回答完成后仍然可见。
- 只有包含助手文字的过程区自动展开；纯工具调用和工具结果仍保持原有折叠行为，避免无文字过程增加界面噪音。
- 继续复用现有历史消息与实时事件的合并逻辑，兼容当前 Web 入口以及未来的 WebView/EXE 前端容器。

## 验收标准

- 助手在工具调用期间输出的非空文字，在任务完成后仍能在对话中看到。
- 文字内容与对应工具过程保持在同一聊天轮次中，不因最终回答接管而消失。
- 只有工具调用、工具结果而没有助手文字时，过程区不强制展开。
- 前端单元测试和生产构建通过，且不使用浏览器自动化测试。
