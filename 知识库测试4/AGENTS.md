# 知识库：意识科学

## 1. 知识库范围

- **主要领域**：意识科学（Consciousness Science）
- **已入库资料**：11 份 Markdown 文档，覆盖高阶理论（HOT）、全局工作空间理论（GWT）、整合信息论（IIT）、元认知、自我意识、机器意识，以及 ARC-COGITATE 对抗实验进展
- **资料身份**：全部为讲稿/笔记/二次分析（ljg-* 技能输出 + 学习笔记），非原始论文
- **排除内容**：`知识库Skill草案.md`（管理文件，不入库）

## 2. 目录职责

- `raw/` — 已确认的原始资料层，原文完整保护，不修改
- `wiki/` — Agent 维护的知识层，含索引（index.md）、日志（log.md）和资料摘要（sources/）
- `inbox/` — 尚未入库的暂存层
- `archive/` — 退出活跃知识库但可恢复的归档层

## 3. 原文保护

- 不改写、覆盖或删除 `raw/` 中的资料
- 移动资料时保持附件和相对链接有效

## 4. 查询规则

- 普通问答先读 `wiki/index.md`
- 再读相关摘要（`wiki/sources/`）
- 必要时回查 `raw/`
- 明确区分库内知识、Agent 推断和知识缺口
- 普通问答默认只读

## 5. 写入规则

- 只有用户主动要求整理、加入、修订或归档知识时才修改 Wiki
- Agent 可以询问是否保存，但不得默认保存

## 6. 来源规则

- 本库全部资料为讲稿/笔记/二次分析，不继承原论文可信度
- 同一来源的多个表达层（原文、格式副本、翻译）不计为多份独立证据
- 综合结论必须可追溯到资料摘要和原文件

## 7. 联网规则

- 只有用户要求联网时才搜索
- 搜索结果不自动进入知识库
- 下载文件先进入 `inbox/`

## 8. 更新规则

- 新增、审阅、归档和巡检后更新 `wiki/index.md`
- 向 `wiki/log.md` 追加记录，不重写历史
