# 2026-09-15 Electron 本机双击启动

## 背景/原因

现有 Web 启动脚本会启动 Python 后端与 Vite 开发服务，再打开浏览器。用户希望在当前 Windows 电脑上双击桌面图标直接进入桌面窗口；这一步先验证桌面入口，不制作安装包或独立 EXE。

## 具体设计

- 入口层 / Channel Layer：Electron 主进程负责单实例窗口、本地 FastAPI 启动和就绪检查，窗口加载 FastAPI 托管的前端构建产物；React 页面及 `/api` 调用保持原样。
- 启动时检查项目 `.venv` 与前端构建文件。`8787` 上已有同项目后端则复用，异项目或非 agent-alpha 服务则提示端口占用，不结束该进程。
- Electron 退出时只结束自己启动的后端和其中任务；复用 Web 后端时仅关闭桌面窗口，Web 任务继续运行。旧 Web 启动脚本也改为识别并复用同项目后端，不再无条件结束 `8787` 上的服务。
- 首次准备命令安装锁定的 Electron 依赖、构建前端、从既有横幅右侧生成方形 Windows 图标，并创建指向项目内 Electron 程序的桌面快捷方式。项目搬家后需重新执行准备命令。
- 桌面页面维持隔离和沙箱，不向页面开放 Node.js 或任意系统接口；限制窗口跨地址跳转。
- 本次不改变 Gateway API、会话格式、Agent Runtime、权限流程或项目数据目录；安装包、便携 EXE 和数据迁移留待后续迭代。

## 验收标准

- 双击快捷方式只打开一个 Electron 桌面窗口，不打开浏览器或命令行窗口；重复双击唤起已有窗口。
- 同项目 Web 后端可复用，异项目占用端口、缺少环境或启动失败时显示明确错误；退出仅影响桌面版拥有的后端。
- 项目、会话、聊天、权限询问、上传及文件预览继续通过现有本地 API 工作；前端构建与边界测试通过，不使用浏览器自动化测试。
