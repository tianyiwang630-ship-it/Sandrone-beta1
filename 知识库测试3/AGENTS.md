# 知识库规则 — 意识科学

## 知识库范围
- **主题**: 意识科学（Consciousness Science），涵盖高阶理论（HOT）、全局工作空间理论（GWT）、元认知、自我意识、机器意识。
- **入库范围**: `raw/` 中 10 份已确认的资料（综合笔记、论文讲稿 ×6、概念解剖 ×1、七拍叙事 ×3）。
- **明确排除**: `知识库Skill草案.md`（知识库管理文件）；所有未明确加入 `raw/` 的内容。

## 目录职责
- `raw/` — 原始资料层。不改写、不覆盖、不删除原文。
- `wiki/` — Agent 维护的知识层。
  - `wiki/index.md` — 知识库首页与导航
  - `wiki/sources/` — 每份资料的摘要
  - 综合页 — 跨资料的综合知识组织
- `inbox/` — 尚未入库的暂存层。普通问答不引用。
- `archive/` — 退出活跃知识库但可恢复的归档层。

## 原文保护
- 不得改写、覆盖或删除 `raw/` 中的用户资料。
- 移动资料时保持附件和相对链接有效。

## 查询规则
- 普通问答先读 `wiki/index.md` 定位知识。
- 再读相关综合页和 `wiki/sources/`。
- 必要时回查 `raw/` 核实原文。
- 回答时标明依据的 Wiki 页面或原始资料。
- 明确区分库内知识、Agent 推断和知识缺口。
- 普通问答默认只读，不修改 Wiki。

## 写入规则
- 只有用户主动要求整理、加入、修订或归档知识时才修改 Wiki。
- Agent 可以询问是否保存新知识，但不得默认写入。

## 来源规则
- 区分原始论文、论文讲稿、概念分析、七拍叙事、笔记和 Agent 推断。
- 同一来源的多种表达层（如 Fleming 2024 的讲稿版和叙事版）不计为多份独立证据。
- 综合结论必须可追溯到资料摘要和原文件。

## 联网规则
- 只有用户要求联网时才搜索。
- 搜索结果不自动进入知识库；下载文件先进入 `inbox/`。

## 更新规则
- 新增、审阅、归档和巡检后更新 `wiki/index.md` 和受影响的页面。
- 向 `wiki/log.md` 追加记录，不重写历史。
