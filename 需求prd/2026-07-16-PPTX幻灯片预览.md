# PPTX 幻灯片预览

日期：2026-07-16

## 背景/原因

右侧文件抽屉已经支持文本、Markdown、Word、PDF 和静态 HTML 预览，但点击 `.pptx` 文件时只能看到“不支持预览”的提示。用户需要在现有预览区直接看见幻灯片页面，同时不希望为了预览引入 PowerPoint、LibreOffice、服务端格式转换或图片缓存等重型链路。

## 具体设计

- Gateway 文件接口层识别 `.pptx` 为可预览文件，并允许通过现有原文件接口安全读取 PPTX；路径仍受 project workspace 边界约束。
- Web 入口与输出/UI 层新增独立 PPTX 预览组件，在前端本地解析文件并以连续纵向列表显示幻灯片。
- 预览保留文字、图片、背景和基本布局，但不承诺完全还原 PowerPoint；不支持 `.ppt`、动画、音视频播放、备注、编辑、搜索或导出。
- PPTX 渲染依赖仅在用户实际点击 `.pptx` 时动态加载，不增加日常聊天及其他文件预览的首屏负担。
- 长演示文稿采用延迟解析、媒体延迟解码和窗口化挂载；用户快速切换文件或关闭抽屉时取消旧请求并释放渲染资源。
- 损坏、伪造或超出安全解析限制的 PPTX 在预览区显示错误提示，不影响文件目录和其他预览功能。
- 本次不调用 PPTX Skill，不修改 Agent Runtime、Agent Loop、会话编排或工作区持久化链路。
