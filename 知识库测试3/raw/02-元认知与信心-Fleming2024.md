# 问题

## 主角：一个领域里的两个部落

这个故事的主角不是一个人，是一个领域——元认知（metacognition）——但它裂成了两个互不说话的部落。

**部落一**研究"信心"——你的视觉系统辨别一条线是左斜还是右斜时，大脑里怎么编码%100的不确定性的？这个部落开 fMRI，记录猴子单细胞放电，建概率编码模型。他们发现视觉皮层里有一群神经元，它们的放电模式天然携带了"这条线我看不太清"的信号。这是**亚个人层面（subpersonal）** 的加工——发生在你的神经元里，跟你的"感受"没关系。

**部落二**研究"元认知"——你为什么知道自己记住了今晚要买什么，又为什么觉得自己记不住那个人的名字？为什么你有时候过度自信，有时候又不够自信？这个部落做行为实验、问被试信心评分、研究前额叶损伤患者为什么"不知道自己不知道"。这是**个人层面（personal-level）** 的现象——你的信念、你的判断、你关于自己的知识。

两个部落之间几乎不说话。信心研究的人觉得元认知那帮人太模糊、太现象学；元认知的人觉得信心研究那帮人太微观、不问"真正重要"的问题。

## 困境：两套语言的鸿沟

这种割裂不只是学术政治问题——它导致了三件坏事：

**第一，同一个词说两件事。** "信心"这个词，部落一用来指神经元的概率编码（"这个神经元的放电率编码了方向不确定性"），部落二用来指你自己的感受（"我觉得我有70%的把握"）。两件事在脑子里的机制完全不同，但共用一个词 = 交流灾难。

**第二，各自不知道对方的发现。** 部落一已经搞清楚了视觉系统怎么编码不确定性——概率群体编码、贝叶斯推理——但不知道这些信号怎么变成"我感觉自己是对的"这个主观体验。部落二已经发现了元认知判断的种种偏差和扭曲——过度自信、流畅性错觉、内感受干扰——但不知道这些偏差在计算层面发生在哪一步。

**第三，干预不知靶点在哪。** 各种训练、药物、脑刺激号称能"提升元认知"——但不知道提升的是哪个计算环节：是对不确定性的敏感性？是把不确定性转成信心报告的转换函数？还是对信心的社会沟通能力？不知道靶子，治疗就是瞎打。

Fleming 想做的：**在两个部落之间修一座桥。**

# 翻译

## 转折：把核心概念换成一个——命题信心（Propositional Confidence）

Fleming 做了一个概念上的擒纵动作：他说，我们不要再用"信心"和"元认知"当两个东西了。把它们统一到一个概念下——**命题信心（propositional confidence）**。

命题信心的定义：你对自己某个（假设性的）决策或行动有多大把握。

比如：
- "我有多大把握刚才那条线是向左偏的？" → 感知信心
- "我有多大把握莎士比亚生于1564年？" → 记忆信心
- "我有多大把握我能踢进这个球？" → 技能信心

这些看起来是不同的东西（视觉、记忆、运动），但在计算层面，它们共享同一个结构：

> 把对**世界的不确定性**（"这条线的方向可能是左偏，但我不确定"），转变成对**自己的命题的不确定性**（"我认为这条线左偏——我有多确信自己是对的？"）。

前者是"以世界为中心的参考系"（world-centered reference frame），后者是"以自我为中心的参考系"（self-centered reference frame）。**这个参考系转换（reference frame shift）是整个框架的支点。**

## 解法：信心形成的五个计算阶段

基于大量实验证据，Fleming 把"信心"拆成了五个计算阶段，每个阶段有独立的计算机制和神经基础：

```
世界中心参考系                  自我中心参考系
─────────────                   ─────────────

 感觉/记忆/运动系统             元认知系统

 ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
 │Stage 1   │   │Stage 2   │   │Stage 3   │   │Stage 4   │  行为输出
 │不确定性   │→  │参考系转换  │→  │全局广播   │→  │自我模型   │→ 信心报告
 │编码       │   │→命题信心  │   │+ 沟通    │   │影响       │
 │(V1, LIP, │   │(vmPFC,   │   │(额极皮层) │   │(dmPFC,   │
 │ 海马等)   │   │ pMFC)    │   │          │   │ TPJ)     │
 └──────────┘   └──────────┘   └──────────┘   └──────────┘
      ↑                                              ↑
      └───── Stage 0 (基础)：各领域感知/记忆/运动加工 ──┘
```

### Stage 1：不确定性编码（世界中心）

**做什么**：编码感觉/记忆/运动信号的内在不确定性。

**机制**：概率群体编码——一群神经元各自编码不同特征值（如方向、颜色），整个群体的活动模式天然携带了信号有多不确定的信息。如果群体编码的是宽分布（很多方向都有可能），不确定性高；窄分布（几乎确定是左偏），不确定性低。

**证据**：
- V1 神经元群体编码方向的不确定性（Ma et al. 2006）
- LIP 区（外侧顶内沟）的变异性预测猴子的"退出选择"——当证据弱时，猴子选择退出赌局（Kiani & Shadlen 2009）
- 多感官整合中，两个通道的权重与其不确定性成反比（Ernst & Banks 2002）

**关键点**：这些不确定性信号存在于各种认知领域——感知、记忆、运动控制——但**它们本身不是元认知**。它们就像温度计，能测温度（不确定性），但不知道自己在测温度。

### Stage 2：参考系转换 → 命题信心（世界中心 → 自我中心）

**做什么**：把"世界的不确定性"转成"对自己的命题的确定性"。这个转换是关键：从编码"这条线有60%概率是左偏"变成"我有70%的把握我当时看到的是左偏"。

**机制**：一个"自我中心参考系"的表征。现在不确定性不再关于外部世界，而是关于**我自己的心理状态**。

**证据**：
- vmPFC（腹内侧前额叶）/ pgACC（前扣带回膝下部）的活动追踪命题信心（Bang & Fleming 2018）
- 这个区域的活动独立于具体的感知证据——即使刺激相同、判断相同，信心变化时这里也活动变化
- meta-d'——控制了一阶表现后的元认知敏感性指标——测量就是这个阶段的效率

**关键点**：这一阶段才真正算"元认知"。它满足"把心理状态本身当作正确性条件"的定义。

### Stage 3：全局广播与社会沟通

**做什么**：把命题信心变成可用于行为控制和社会沟通的信号。

**证据**：
- 额极皮层（lateral frontopolar cortex, BA 10）在需要做明确信心报告时活动增加（Fleming et al. 2012）
- 社会决策中，vmPFC 追踪私人信心，额极皮层额外编码"私人→公共"的映射调整（Bang et al. 2020）
- 额极皮层损伤/干扰会损害元认知效率（Fleming et al. 2014）

**关键点**：这里分离了两个东西——"我有多确信"（私人）和"我报告我有多确信"（公共）。两者可能偏离，而额极皮层负责管理这个映射。

### Stage 4：自我模型的影响（基于模型的元认知）

**做什么**：信心判断不仅受当前证据驱动，还受你先验的、关于自己认知系统的信念影响。

**机制**：你对自己"如何工作"有一个内隐模型——比如"反应快=更可能正确"、"心率变化=我紧张了=我可能不太擅长这个"。

**证据**：
- 流畅性错觉：字体更大或面孔更亮 → 被试更容易说"记住了"——尽管实际表现没变（Busey et al. 2000; Hu et al. 2015）
- 内感受干扰：潜意识呈现的厌恶面孔改变心率 → 影响对随机点运动的信心——即使跟任务无关（Allen et al. 2016）
- 虚假反馈操纵信心：告诉被试"你比其他人都差" → 他的先验信念改变信心 → 实际表现完全不变（Marcke et al. 2022）

**神经基础**：心理理论网络（dmPFC、TPJ）可能会参与基于模型的元认知——因为你推理自己的心理状态，用的可能是和推理别人心理状态一样的资源（Nicholson et al. 2021）。

### Stage 5（隐含）：元认知控制

**做什么**：命题信心一旦形成，被用来指导行为——比如要不要退出赌局、要不要修改答案、要不要尝试记忆提取。

**证据**：
- 信心越高的退出率越低（Kiani & Shadlen 2009）
- 信心引导任务间的注意力分配（Aguilar-Lleyda & de Gardelle 2021）

## 结局：桥建好了，但两头还没通

Fleming 给出了一个清晰的路线图——把"信心形成"拆成五个计算阶段，每个阶段有其特定的输入、输出、神经基础、和失效模式。

**最反直觉的副发现**：你的信心判断其实**不是**直接读了你自己的内部信号。更像是一个推理过程——你像推理别人一样推理自己。没有"直接内省通道"——你推导出自己多确信，用的信号和你推导别人多确信用的信号是同一套（或共享一部分）资源。

这与日常直觉完全相反——我们总觉得"我知道自己有多确定"是直接的、透明的、无中介的。实际上它是推理出来的，所以它才那么容易出错：流畅性错觉、内感受干扰、虚假反馈——这些都能骗过你的信心，**你自己还不知道自己被骗了**。

## 对意识科学的启示

| 层面 | 含义 |
|------|------|
| **与 C0/C1/C2 的关系** | Stage 1 ∈ C0（亚个人不确定性）；Stage 2 ∈ C2（命题信心 ≈ 元认知）；Stage 3 ∈ C1（全局广播） |
| **与 HOT 的关系** | 命题信心（Stage 2）就是高阶表征的一种形式——"关于心理状态的心理状态"。Fleming 为 HOT 提供了一个计算层面的实现机制 |
| **与 ISAM 的关系** | Stage 4（自我模型）与 ISAM 的"预测编码→元认知"完全对齐——内感受信号通过自我模型影响信心 |
| **与临床的关系** | 五个阶段各有易损节点——eg. 焦虑 = Stage 4 的威胁性先验过强；精神分裂 = Stage 2 的参考系转换异常 |

# 核心概念

| 概念 | 定义 |
|------|------|
| **命题信心** | 对自身（假设性）决策或行动的正确性的信念程度。统一了"信心"和"元认知"两个领域 |
| **世界中心参考系** | 关于外部世界的不确定性——"这条线60%可能是左偏" |
| **自我中心参考系** | 关于自身心理状态的不确定性——"我有70%把握我判断对了" |
| **meta-d'** | 控制一阶表现后的元认知敏感性指标。一阶辨别能力不变时，meta-d' 越高说明元认知效率越高 |
| **自我模型** | 个体关于自身认知系统的（内隐）信念——你觉得自己记性好不好、反应快不快、在什么条件下表现好——影响信心判断 |
| **亚个人 vs 个人** | 亚个人 = 神经层面的事件（如群体编码的不确定性）；个人 = 可报告的主观体验（如"我觉得有把握"） |

# 洞见

> **信心不是一种直接的感受——是你大脑推理自己之后得出的结论。**

我们通常觉得"我知道我知道"是一种直接的、透明的感觉——就像你看到红色那样直接。Fleming 告诉我们这完全是错的。你的信心是一种**推理的产物**——你从一堆线索里推导出"我有多确信"。这些线索包括当前证据的强度、你的反应速度、你的心跳、你过去的信念——但**不包括**"直接内省"。

这就解释了三件看似奇怪的事：
1. 为什么信心可以脱离表现独立涨跌（ARC-FOHO 的主观膨胀）——因为信心推理用了一阶证据之外的其他线索
2. 为什么信心可以被虚假反馈、流畅性、内感受这些"不相关"的东西操纵——因为它们也是推理的输入
3. 为什么前额叶损伤后任务表现还在但元认知受损——因为推理自己需要前额叶，但一阶感知不需要

# 博导审稿

这篇不是一篇报告新实验的论文——是 Fleming 作为元认知领域最重要的研究者之一，在 Annual Review of Psychology 上写的**领域综述兼理论综合**。

**优势**：
1. 桥建得有说服力。"命题信心"这个概念确实统一了信心和元认知两个传统。
2. 五个计算阶段的拆分有实证基础、有神经对应、有可操作的定义——不是空中楼阁。
3. 对干预的启示非常务实：知道了靶点在哪一步，才能设计精准的干预。

**局限**：
1. 各阶段之间如何相互作用的讨论仍偏浅。作者自己也承认这是"为教学方便而拆开"。
2. 与 HOT/GWT 等意识理论的关系没有展开——这篇在意识科学的大图上缺了一个坐标系。
3. 自我模型这个盒子仍然偏黑——说了"有模型影响"，但模型本身的结构、学习方式、更新机制谈得不够。

# 启发

> **下次你觉得自己"很有把握"的时候，问自己一声——我这份把握，到底是从证据来的，还是从我对自己讲的故事来的？**
