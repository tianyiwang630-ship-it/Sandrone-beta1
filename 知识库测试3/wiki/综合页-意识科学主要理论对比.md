# 意识科学主要理论对比

## 四大理论阵营

| 维度 | 全局工作空间理论 (GWT/GNW) | 高阶理论 (HOT) | 整合信息论 (IIT) | 一阶/局部回馈理论 |
|------|--------------------------|---------------|-----------------|-----------------|
| **核心主张** | 意识 = 信息被广播到前额-顶叶全局工作空间 | 意识 = 高阶表征（二阶状态指向一阶状态） | 意识 = 系统整合的信息量（Φ值） | 意识 = 感觉皮层局部递归加工足够强 |
| **关键机制** | 非线性"点火"事件 → 全脑广播 | 前额叶自动生成高阶表征 → 一阶信号被标记为有意识 | 因果动力结构中的信息整合度 | 局部回馈连接 → 感觉表征达到意识阈值 |
| **核心脑区** | 前额叶 + 顶叶 + 扣带回 + 感觉区 | 前额叶（高阶表征） + 后部感觉区（一阶内容） | 后部热区（枕-顶-颞叶） | 初级/高级感觉皮层 |
| **神经标记** | P3b 波、γ 远距离同步、点火模式 | meta-d'、折叠 X 模式（pMFC） | 持续神经元同步（被 ARC-COGITATE 证否） | 局部 γ 波段同步、V1 回馈 |

## ARC-COGITATE 决战结果

| 维度 | GWT 成绩 | IIT 成绩 |
|------|---------|---------|
| **解剖位置**（意识在哪？） | 部分得分（前额叶参与） | 得分（后部热区强激活+内容解码） |
| **机制验证**（怎么发生？） | 失分（没测到预期点火） | 失分（没测到持续同步） |
| **综合** | 共享机制存在，前额叶角色需下调 | 位置正确，计算机制需重写 |

## 理论关系图谱

```
一阶理论（局部递归）          HOT             GWT              IIT
    │                         │               │               │
感觉皮层                  前额叶参与       前额叶+顶叶      后部热区
无额外高阶要求             高阶表征         全局广播         因果整合
                          不需自我意识     需"点火"事件      Φ值计算
```

**关键张力**：GWT 和 IIT 在 ARC-COGITATE 中双输 → 为 HOT 让出空间。ARC-FOHO 将直接检验 HOT 与一阶理论的预测分歧。
